# QuietSentry 基础组件规范（UI-03）

> 版本：v1.0（评审稿）｜来源：T04776 / UI-03（T04779 定义、T04780 实现、T04781 接入）
> 设计令牌基线：`app/src/main/res/values/colors.xml`（`qs_*` 单一来源，T04777 收敛）、`dimens.xml`（`qs_*` 间距/字号/圆角）。
> 本文件只定义「规范与命名约定」，**不含实现**；实现见 T04780，页面接入见 T04781。

## 1 总则

- 所有可见颜色统一走 `@color/qs_*`（含 `qs_inline_*` 精确匹配别名，待语义归并后并入 `qs_*`）。
- 所有字号/间距/圆角统一走 `@dimen/qs_*`，禁止布局内硬编码 `dp/sp`（尺寸 token 化见 T04778 延后项）。
- 暗色优先：黑底（`qs_bg`）+ 半透明白卡片（`qs_surface`）+ 单一青色强调（`qs_accent`）。
- 无障碍：每个交互/状态元素必须有 `contentDescription`；纯装饰元素标 `importantForAccessibility="no"`；状态不得只靠颜色区分（图标 + 文字）。
- 系统字号放大 1.3 倍不得截断；减少动态效果（`reduceMotion`）时动画直接跳终态。

## 2 组件清单与资源命名

| 组件 | 用途 | 布局资源 | 背景 drawable | 样式 |
| --- | --- | --- | --- | --- |
| 主按钮 PrimaryButton | 最高优先级动作（如扫码配对） | `comp_primary_button.xml` | `comp_btn_primary_bg.xml`（selector） | `Widget.QuietSentry.PrimaryButton` |
| 次按钮 SecondaryButton | 次级动作（配对码/手动 IP） | `comp_secondary_button.xml` | `comp_btn_secondary_bg.xml`（selector） | `Widget.QuietSentry.SecondaryButton` |
| 状态卡 StatusCard | 单设备状态聚合展示 | `comp_status_card.xml` | 复用 `qs_surface` + `qs_radius_card` | `Widget.QuietSentry.StatusCard` |
| 设备卡 DeviceCard | 设备列表项（缩略图 + 名 + 状态角标） | `comp_device_card.xml` | 复用 `qs_surface` + `qs_radius_card` | `Widget.QuietSentry.DeviceCard` |
| 异常横幅 ErrorBanner | 离线/断流/权限缺失/配对失效统一提示 | `comp_error_banner.xml` | `comp_banner_bg.xml`（selector） | `Widget.QuietSentry.ErrorBanner` |
| 空态容器 EmptyState | 无设备/无结果时的引导（主+次按钮） | `comp_empty_state.xml` | 复用 `qs_surface` + `qs_radius_card` | `Widget.QuietSentry.EmptyState` |

命名约定：组件统一前缀 `comp_`；背景 selector 统一放 `res/drawable`；样式统一放 `res/values/styles.xml` 的 `Widget.QuietSentry.*` 家族，布局用 `style="?attr/..."` 或显式 `style="@style/Widget.QuietSentry.Xxx"` 引用，避免逐属性复制。

## 3 各组件规范

### 3.1 主按钮 PrimaryButton

- 背景：`qs_accent`（#FF00BFA6）；圆角 `qs_radius_button`（10dp）；高度 48dp（实现时评估是否补 `qs_size_button` token）。
- 文字：`qs_text`（#FFFFFFFF），字号 `qs_text_body`（15sp），字重 Medium；内边距水平 `qs_space_16`。
- 状态：
  - 默认：`qs_accent` 底 + 白字。
  - 按压（pressed）：底变 `qs_accent_soft`（#3300BFA6）叠加，或明度降一档。
  - 禁用（disabled）：底 `qs_surface`、字 `qs_text_muted`、不可点击。
- 无障碍：`contentDescription` 取按钮文案本身；`minHeight=48dp` 满足触控目标。

### 3.2 次按钮 SecondaryButton

- 背景：透明或 `qs_surface`；边框 1dp `qs_accent`（或 `qs_text_muted` 低调态）；圆角 `qs_radius_button`。
- 文字：`qs_accent`（主次级）或 `qs_text`（低调次级），字号 `qs_text_body`。
- 状态：按压底变 `qs_accent_soft` 低透明；禁用字 `qs_text_muted`、无边框高亮。
- 用途：空态中「配对码 / 手动 IP」作为次按钮，视觉权重明显低于主按钮（扫码）。

### 3.3 状态卡 StatusCard

- 容器：`qs_surface` 底 + `qs_radius_card`（20dp）+ 内边距 `qs_space_16`；阴影用 elevation 或 1dp 描边（暗色下用 `qs_text_hint` 低透明描边更稳）。
- 内容：状态色点（`qs_ok` / `qs_warn` / `qs_danger` / `qs_idle`）+ 主文案 `qs_text` + 副文案 `qs_text_muted`（字号 `qs_text_status` 13sp）。
- 状态色点直径 8dp，`contentDescription` 描述状态语义（如「在线」「告警」），不单靠颜色。

### 3.4 设备卡 DeviceCard

- 容器同 StatusCard 卡片规范；左侧实时缩略图区（占位 `qs_surface`，加载失败回退 `qs_idle` 灰），右侧设备名 `qs_text` + 状态角标（复用状态色）。
- 点击整卡进入观看；角标 `contentDescription` 说明设备状态；缩略图为装饰标 `no`。

### 3.5 异常横幅 ErrorBanner

- 背景：`qs_danger` 低透明（`qs_inline_danger_93` 或实现时评估 `qs_danger` + 12% 蒙版），圆角 `qs_radius_card`，内边距 `qs_space_12`。
- 结构：左图标（状态语义，如离线云/断流/锁/链接断开）+ 一句原因 `qs_text` + 唯一主动作按钮（次按钮样式，文案直达：打开设置 / 重新配对 / 重试）。
- 四类覆盖：离线、断流、权限缺失、配对失效；组件只承接展示，触发逻辑沿用现有各页实现，不重复造状态机。
- 无障碍：整条 `contentDescription` = 原因 + 动作；动作按钮独立可达。

### 3.6 空态容器 EmptyState

- 居中：图标（`qs_text_hint`）+ 标题 `qs_text`（20sp 标题或 15sp 正文）+ 说明 `qs_text_muted` + 主按钮（扫码）+ 次按钮（配对码 / 手动 IP）。
- 三条配对路径必须一屏全部可见，不得退回「先点添加再选方式」；主按钮视觉权重高于两个次按钮。
- 对应 G3 / UX-02；TalkBack 依次读出「图标 → 标题 → 说明 → 扫码 → 配对码 → 手动 IP」且均可走通。

## 4 状态化背景 selector 约定

- 每个可按压组件一个 `comp_xxx_bg.xml`，用 `<selector>` 包含 `state_pressed` / `state_enabled=false` / 默认三态。
- 颜色仅引用 `@color/qs_*`，不写裸色值；pressed 用 `qs_accent_soft` 类低透明叠加，禁用用 `qs_surface`/`qs_text_muted`。

## 5 验收（供 T04780/T04781 引用）

- 全仓组件背景色值扫描为 0 裸色（已在 T04778 达成色彩层）；布局引用统一走 token。
- 6 个组件至少接入 2 个真实页面（建议：空态容器接入设备列表空态、异常横幅接入首页/实时页），TalkBack 走查通过。
- 系统字号 1.3 倍、减少动态效果开关下无截断/无循环动画。
- 设计与代码数值一致（本规范与 `colors.xml` / `dimens.xml` 数值同源）。

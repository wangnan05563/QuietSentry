# 静哨 QuietSentry · 合规与商店审核材料

> 对应 MTask：W04 / T03735　依据：[PRD-QuietSentry.md](../PRD-QuietSentry.md) §2.4（平台与合规约束）、FR-01、FR-14、D6
> 状态：草稿 v1.0，供商店提交前逐条核对；文中带 `[待定]` 的条目必须在上架前补齐。

## 1 立场

产品把"屏幕熄灭后仍能采集"公开地写在商店描述、首次启动说明与常驻通知里。合规策略只有一条：**不靠隐蔽换取体验，靠披露换取信任。**

因此以下词句在所有对外文案中禁用：偷拍、无痕、隐形、秘密监控、不被发现、防出轨、取证神器。

## 2 首次启动合法用途确认（FR-01）

### 2.1 三屏说明（文案草案）

**第 1 屏 · 这是什么**

> 静哨把你家里闲置的 Android 设备变成一台值守摄像头。
> 屏幕可以熄灭，画面仍会保存在这台设备本地。

**第 2 屏 · 数据去哪**

> 画面默认只保存在这台设备里，不上传、不经过我们的服务器。
> 是否分享给家人，由你决定。

**第 3 屏 · 不能用来做什么**

> 请只在你本人拥有，或已获得明确授权的场所使用。
> 在他人不知情的情况下拍摄他人生活空间，在多数地区属于违法行为。
> 本产品会持续显示采集通知，且无法关闭。

### 2.2 确认门

- 勾选项文案：**「我确认仅在本人拥有或已获授权的场所使用本产品」**
- 未勾选时：「开始使用」不可点击；其余功能不可用，仅可查看隐私说明与卸载指引。
- 记录内容：确认版本、确认时间、设备型号；**只存本机**，不上传。
- 条款版本升级后再次弹出，旧记录保留用于追溯。

### 2.3 英文版（Google Play 提交用）

> QuietSentry turns a spare Android device you own into an on-device security camera.
> Screen can stay off while footage is recorded and kept **on this device**.
> Use it only on premises you own or are explicitly authorized to monitor.
> A persistent notification is always shown while capture is active and cannot be disabled.

## 3 隐私说明（应用内可查看）

| 数据 | 是否收集 | 去向 | 保留 |
| --- | --- | --- | --- |
| 视频与照片 | 是 | 应用私有目录（`files/clips`、`files/private_gallery`） | 本地，按保留策略清理（当前仅增不删，见 §7） |
| 设备型号、镜头能力 | 是 | 仅本机，用于画质选项 | 本地 |
| 合法用途确认记录 | 是 | 仅本机 | 本地，卸载即删 |
| 崩溃日志 | 否（P0 不收集） | — | — |
| 账号、手机号、位置 | 否 | — | — |

承诺边界：

- **无账号、无订阅、无云端中继**（PRD D3）。
- 局域网传输默认 TLS；公网访问走用户自建的 Tailscale / WireGuard，产品不持有组网密钥（FR-14）。
- 卸载应用即删除全部本地数据（未提供云备份，PRD FR-14 明确 P0/P1 不做云备份）。

## 4 权限清单（商店 Data Safety 与权限声明用）

| 权限 | 用途（对外表述） | 触发时机 | 拒绝后果 |
| --- | --- | --- | --- |
| `CAMERA` | 在前台服务中录制视频、黑屏模式下拍照 | 首次进入值守或黑屏页 | 无法使用采集功能 |
| `RECORD_AUDIO` | 录制环境声音（可选） | 与相机权限同批请求 | 只录画面，无声音 |
| `POST_NOTIFICATIONS`（Android 13+） | 显示"正在采集"的持续通知 | 首次进入值守 | 通知不可见；按 PRD §10.5 应禁止启动值守（待收紧，见 §7） |
| `FOREGROUND_SERVICE` | 支持前台服务运行 | 安装时 | — |
| `FOREGROUND_SERVICE_CAMERA` | 声明前台服务为相机类型 | 安装时 | Android 14+ 无法后台采集 |
| `FOREGROUND_SERVICE_MICROPHONE` | 声明前台服务含麦克风类型 | 安装时 | 无法后台录音 |

`<uses-feature android:name="android.hardware.camera.any" android:required="true" />` 表示无相机设备不安装。

当前申报最小集，**未申请**存储、位置、通讯录、电话、广告 ID。

## 5 商店描述（Google Play）

### 5.1 短描述（≤80 字符）

> 把闲置 Android 设备变成本地值守摄像头：熄屏可录，数据不出家门。

### 5.2 完整描述（草案）

> **把闲置手机变成一台值守摄像头**
>
> 家里的旧手机、旧平板放着也是放着。静哨让它在屏幕熄灭的情况下继续记录，画面保存在设备本地，不经过任何服务器。
>
> · 值守模式：屏幕熄灭仍持续录制，30 秒分片保存，进程被系统回收也只损失最后一片
> · 黑屏记录：屏幕全黑不显示取景画面，单击拍照、双击切换前后镜头
> · 本地优先：无账号、无订阅，画面默认不出设备
> · 状态透明：采集期间始终显示常驻通知，可随时停止
>
> **请仅在你本人拥有或已获授权的场所使用。** 在他人不知情的情况下拍摄他人生活空间，在多数地区属于违法行为。本应用会在采集期间持续显示通知，且无法关闭。
>
> 目前版本为本地录制基础版，实时观看与家庭成员共享功能将在后续版本提供。

### 5.3 需要避免的说法

| 不要写 | 改写为 |
| --- | --- |
| 熄屏偷拍 / 无痕录制 | 熄屏记录，采集期间有常驻通知 |
| 不被发现的监控 | 屏幕不发光，但系统通知始终可见 |
| 防出轨 / 取证神器 | 用于本人场所的家庭值守 |

## 6 审核说明材料

商店对 `camera` / `microphone` 前台服务类型要求说明用途并提供可复现的演示路径。提交时附以下内容：

### 6.1 前台服务用途声明（英文，提交表单用）

> QuietSentry uses a foreground service with type `camera` (and `microphone` when the user grants audio permission) to continue recording while the device screen is off. This is the core use case: a spare device is placed on a shelf and must keep recording without keeping the display on.
> A persistent, non-dismissible notification is displayed for the entire duration of capture, and it contains a "Stop" action. Capture cannot start without the user pressing "Start guard" inside the app.

### 6.2 审核演示步骤

1. 安装后首次打开：完成三屏合法用途确认（勾选后才能继续）。
2. 授予相机、麦克风、通知权限。
3. 点「开始值守」→ 观察状态栏出现常驻通知。
4. 按电源键熄灭屏幕 → 等待 1 分钟 → 唤醒并点通知中的「停止」。
5. 点「黑屏记录」→ 屏幕全黑 → 单击拍照 → 长按退出。
6. 通过 `adb shell run-as com.quietsentry.app ls files/clips files/private_gallery` 可见本地文件（审核侧可要求提供测试包与命令）。

### 6.3 后台相机与"隐蔽"质疑的标准答复

> 本应用不具备隐藏采集的能力：采集开始必须由用户在应用内主动点击；采集期间系统通知常驻且带有停止入口；黑屏模式只改变屏幕显示内容，不改变通知的可见性。黑屏模式的目的是避免夜间屏幕照亮房间，而不是规避用户知情。

## 7 已知缺口与上架前必须补齐

| 缺口 | 风险 | 状态 |
| --- | --- | --- |
| 无通知权限时仍可启动值守 | 与 PRD §10.5 冲突，且是最容易被审核质疑的一条 | ✅ 已修复：`MainActivity` 在缺少 POST_NOTIFICATIONS 时拒绝启动并提示 |
| 无首次启动合法用途确认页 | FR-01 未实现，商店合规硬门槛 | ✅ 已实现：`ConsentActivity` 三屏说明 + 勾选门，确认记录只存本机（`ConsentStore`） |
| 保留策略未实现（只增不删） | 存储无限增长；隐私说明中的"按保留策略清理"尚不成立 | ✅ 已实现（W09）：7 天过期 + 可用空间 50% 配额（`StorageKeeper`） |
| 黑屏模式与值守模式可同时触发相机重绑定 | 值守录像被中断，属于可见缺陷 | ✅ 已修复：`MainActivity` 检测 `CaptureService.isRunning` 后拒绝进入黑屏页并提示 |
| 未提供远程暂停与观看人数显示 | FR-14 要求，当前无观看端 | ✅ 已实现（W24）：`/api/pause`（Guest 禁止）+ `MAX_VIEWERS` 429 + 观看端确认弹窗 |
| 无隐私政策网页 | Google Play 要求提供可访问链接 | 待上架前提供（`[待定]` 托管地址） |
| 快门音地区差异未实测 | 部分市场强制快门声，描述不得承诺静音拍照 | 真机回归时记录（PRD §10.5 能力清单） |

### 7.1 越权与隐私自测用例（W24）

编译级已通过 `assembleDebug`；下列端到端用例需真机执行，当前并入 T03774。

| 编号 | 步骤 | 期望 |
| --- | --- | --- |

## 8 地区与法律提示

- 中国大陆：家庭内部拍摄需注意他人隐私与个人信息保护相关法律；不得用于公共空间对不特定人群的持续拍摄。
- 欧盟 / 英国：涉及 GDPR，家庭纯个人用途有豁免但分享给第三方即可能构成处理个人数据。
- 美国部分州：双方同意录音规则（two-party consent）影响声音录制，应用内需提示用户自行确认当地法律。

应用内不提供法律意见，只提供"仅限本人或已授权场所"的确认门。

# 18 会话代码走查报告：真机验证工具链

## 结论

本轮针对 `real_device_smoke.py`、`soak-inject.ps1`、`stability-7d.ps1` 的走查发现：设计完整，但旧版本存在假 PASS、无限挂起、设备副作用和证据不可信问题。P0/P1 主体已修复；模拟器 `--arm` 与 D3 2 轮、真实三星 `--arm` 均已 PASS，真实 D3/D4/D7 与 7 天/8 品牌仍未执行。

## 已修复

- 执行包：新增 `scripts/package-real-device-kit.ps1`，强制包含 `ui_walk.py`、`scripts/build-lib.ps1`、README、`docs/05`、APK，并做 import/语法自检与 `MANIFEST.sha256`；`-OutDir release` 相对路径导致自检路径二次拼接的问题已修。
- ADB：`soak-inject.ps1`、`stability-7d.ps1` 改为 `ProcessStartInfo + ArgumentList + 异步读输出 + Kill($true)`；超时返回 `ADB_TIMEOUT`，并新增识别 `device not found` / `offline` / `unauthorized`，不再把掉线当 pid=0。失败计入摘要和退出码。
- 设备在线：`real_device_smoke.py` 新增 `ensure_online()`；`--skip-install` 设备离线时明确报“设备不可用”，不再误报“未安装”；`--skip-install` 未给 `--expect-version` 直接 `exit 2`。
- `--arm`：要求 `guardStarted`、`foregroundService`、`fgsNotification` 三项全 true。
- 服务状态：三份脚本均按 `ServiceRecord{...CaptureService...}` 块解析，再判断块内 `isForeground=true`。
- 相册导出：`run()` 开始前记录基线，停止后计算 `exportedDelta`；基线失败记 -1；`verdict` 对 `<=0` 判 FAIL。
- 通知：`monitor` 仅在服务运行时统计缺失；`verdict` 对 `notificationMissing>0` 判 FAIL；dump 去掉 `--noredact`。
- 设备设置：`keep_awake(true)` 保存 `stay_on_while_plugged_in`、`screen_off_timeout` 和三个动画缩放；`finally` 恢复，空值走 `settings delete`。
- 采样中断：只统计“上一点有进程、下一点 pid 变化”，首次 `pid=0` 不计中断。
- D3：默认 `AutoArmMax=3`，第 4/5 次记 `MANUAL_REQUIRED` 并退出 1；`-NoAutoArm` 按 `-Count` 跑满，开始前未运行才 `exit 2`。
- D4：初始 Wi-Fi 必须开启；每次 disable/enable 后回读；结束按原状态恢复，恢复失败即失败。
- D7：要求 `boot_id` 变化 + `boot_completed=1`；`ADB_ERROR` 不当作 `NO_AUTOSTART`。
- 版本：新增 `--expect-version` / `-ExpectVersion`，安装与运行各校验一次。
- 启动：`ui_walk.open_app()` 优先显式 `am start -W -n com.quietsentry.app/.MainActivity`，失败才回退 monkey；修复三星上被其他 App 抢前台后无法稳定回 App。
- 电源框：`start_guard` 先取消旧的“未连接电源”框，启动时点“仍然开始”，并在 `notes` 记“限时 2 小时”。
- ANR：`prepare_ui` 不再只凭 Activity 名判成功；先查 `dumpsys window windows` 的 `Application Not Responding`，再查 UI dump 里的 `isn't responding` / `无响应`，发现即截图并让 `--arm` FAIL。模拟器冷启动确实复现过一次 ANR，真实设备未复现。
- 其他：`prepare_ui` 连续空 dump 3 次 fail fast；`stop_guard` 通知清理轮询 20 秒；“保存失败”不算保存成功；`collect_logs` 只保留本包 FATAL/ANR 与包名相关行；`ui_walk` docstring 改 raw string。

# 静哨 QuietSentry · 交互与视觉设计

> 对应 MTask：W02 / T03733　依据：[PRD-QuietSentry.md](../PRD-QuietSentry.md) §12（UI 升级方案）、FR-04、FR-05、FR-18
> 状态：v1.0（与 MVP 实现对齐，commit ce98af9）

## 1 范围

本文件定义双端（摄像头端 / 观看端）的信息架构、关键界面、设计语言与黑屏手势规范，并说明平板与折叠屏适配规则。

PRD §12 已给出设计原则、信息架构骨架与三张关键界面草图；本文件在其基础上补齐：

- 摄像头端状态页与设置页的具体布局；
- 可落地的设计 token（颜色 / 字号 / 圆角 / 间距 / 动效），并映射到 Android 资源命名；
- 黑屏手势的完整规范，以及 MVP 已实现部分与后续差异；
- 平板、折叠屏、横屏的断点规则；
- 已实现与待实现的对照表（避免设计与代码脱节）。

## 2 设计原则

沿用 PRD §12.1，并补充两条实现约束：

| 原则 | 含义 | 落地约束 |
| --- | --- | --- |
| 暗色优先 | 监控多在夜间，深色减少屏幕干扰 | 仅提供暗色主题，不提供浅色切换，避免两套 token 维护成本 |
| 一屏一任务 | 首页答"设备怎么样"，实时页答"现在发生什么"，事件页答"之前发生什么" | 每个页面只有一个主操作按钮 |
| 状态永远可见 | 采集状态、在线状态、电量始终可见 | 采集状态只能用常驻可见元素表达，禁止隐藏式开关 |
| 破坏性操作可撤回 | 删除 / 停止 / 移除 / 解除配对需确认与短时撤销 | 停止值守弹确认；删除事件提供 5 秒撤销条 |
| 屏幕不制造光 | 黑屏模式屏幕内容为纯黑且不显示预览 | 黑屏页不加载任何亮色图片或动效 |

## 3 双端信息架构

```text
观看端（手机 / 平板）
├─ 首页 · 设备
│  ├─ 设备卡片 → 实时画面
│  ├─ 设备详情（在线、电量、画质、最近事件）
│  └─ 健康诊断（网络、通知权限、保活状态）
├─ 事件
│  └─ 时间轴 → 事件详情 → 播放器 / 快照 / 锁定 / 删除
├─ 消息
│  └─ 告警列表 / 设备状态通知 / 成员邀请
└─ 我的
   └─ 成员与访客 / 存储与保留 / 隐私与安全 / 帮助与诊断

摄像头端（手机 / 平板）
├─ 状态页（默认）
│  ├─ 模式切换：值守 / 黑屏记录 / 已暂停 / 直播中
│  ├─ 主按钮：开始 / 停止
│  └─ 入口：设置、诊断、黑屏记录
└─ 设置
   └─ 镜头与画质 / 检测与计划 / 通知 / 电源与保活 / 高级与集成
```

导航层级不超过三级；摄像头端不设底部导航，状态页是唯一根页面。

## 4 摄像头端关键界面

### 4.1 状态页（值守 / 已暂停）

```text
┌──────────────────────────┐
│ 静哨          摄像头模式 │
│                          │
│  ┌────────────────────┐  │
│  │    实时预览（占位）  │  │
│  └────────────────────┘  │
│  值守中 · 正在采集        │
│  后置镜头 · 1080p · 30s 分片│
│                          │
│  [ 停止值守 ]            │
│  [ 黑屏记录 ]            │
│                          │
│  设置 · 诊断             │
└──────────────────────────┘
```

- 状态行是唯一的状态来源，文案随状态变化（未启动 / 启动中 / 值守中 / 已暂停 / 相机被占用）。
- 「开始值守」失败时必须显示原因（如相机被其他应用占用），不允许停留在"采集中"。
- 停止值守必须二次确认：后台采集一旦开始，用户对"何时停止"的判断最容易出错。

### 4.2 黑屏记录页

```text
┌──────────────────────────┐
│                          │
│                          │
│         （纯黑）          │
│                          │
│  采集中 · 单击拍照         │
│  双击切镜头 · 长按退出     │
└──────────────────────────┘
```

- 页面内容全部为黑色；仅底部保留一行半透明白色提示（alpha 40%，12sp），便于首次使用者发现手势。
- 提示文字可被长按隐藏，避免夜间长时间照亮的残留光。
- 不显示预览、不显示快门动画，拍照反馈只用一次短震动（可关）。

### 4.3 设置页

分组顺序按"最常改 → 最不常改"：镜头与画质 → 检测与计划 → 通知 → 电源与保活 → 高级与集成。

每个设置项必须显示"当前值 + 一句影响说明"，例如「仅充电时值守 · 未充电时最多 2 小时（O2）」。

## 5 观看端关键界面

沿用 PRD §12.3 的设备列表、实时画面草图，补充三类非理想态：

| 状态 | 表现 |
| --- | --- |
| 空态 | 一张说明图 + 「添加摄像头」主按钮，不显示空卡片骨架 |
| 离线 | 卡片显示最后一次在线时间与原因（如"设备关机 / 网络断开"），提供重试 |
| 权限缺失 | 顶部横幅说明缺少通知权限会影响告警，直达系统设置 |

实时画面首帧前显示最近快照与最后在线时间，避免白屏（PRD E4）。

## 6 设计语言

### 6.1 Token 表

| 类别 | Token | 值 | 理由 |
| --- | --- | --- | --- |
| 色彩 | `color_primary` | `#0F766E`（深青绿） | 夜间不刺眼，与"静默值守"气质一致 |
| 色彩 | `color_ok` | `#16A34A` | 值守中 / 在线 |
| 色彩 | `color_warn` | `#D97706` | 低电、未充电限时值守 |
| 色彩 | `color_error` | `#DC2626` | 采集中断、相机被占用 |
| 色彩 | `bg_base` | `#0B0F10` | 接近纯黑但不绝对黑，避免 OLED 低灰阶拖影 |
| 色彩 | `bg_surface` | `#151B1D` | 卡片与浮层 |
| 字体 | 标题 | 20 / 24sp | 系统字体，不引入自定义字体包 |
| 字体 | 正文 | 14–16sp | 与系统设置页一致，降低学习成本 |
| 字体 | 数字 | 等宽数字 | 时间与电量对齐更容易比较 |
| 圆角 | 卡片 | 12dp | 与按钮 10dp 拉开层级 |
| 圆角 | 按钮 | 10dp | 同上 |
| 间距 | 栅格 | 4 / 8 / 12 / 16 / 24dp | 只用这五档，避免随手数值 |
| 动效 | 状态切换 | 150–200ms 淡入 | 夜间不使用弹跳/闪烁 |
| 图标 | 线性 | 2px 描边 | 状态图标必须配文字，不单靠颜色区分 |

### 6.2 Android 资源映射

| Token | 资源位置 | 说明 |
| --- | --- | --- |
| 颜色 | `res/values/colors.xml` | 新增文件，统一命名 `qs_color_*` |
| 字号 | `res/values/dimens.xml` | 命名 `qs_text_title` 等，避免布局内硬编码 sp |
| 间距 | `res/values/dimens.xml` | 命名 `qs_space_4/8/12/16/24` |
| 主题 | `res/values/themes.xml` | 当前 `Theme.QuietSentry` 已是暗色 NoActionBar |

MVP 现有布局使用系统默认 Material 按钮与硬编码 `12dp` 内边距；在 W09 引入正式设计 token 时统一替换，不在本轮做视觉重做。

## 7 黑屏手势规范

| 手势 | 行为 | 反馈 | 实现状态 |
| --- | --- | --- | --- |
| 单击任意处 | 拍照 | 一次短震动（可关） | 已实现（`BlackScreenActivity`） |
| 双击 | 切换前后镜头 | 一次短震动 | 已实现 |
| 长按 1.5 秒 | 退出黑屏模式 | 无 | 已实现（MVP 用长按退出） |
| 长按 1.5 秒（后续） | 隐藏提示控件，再次长按恢复 | 无 | 待实现 |
| 三指点按三次 | 退出黑屏模式 | 无 | 待实现（与长按退出互斥，需统一为一种） |
| 音量键 | 快门 / 录像开关（可配置） | 无 | 待实现（需在设置中声明与系统音量互斥） |

设计裁决：MVP 先用"长按退出"，因为三指点按在纯黑界面缺少可见提示、学习成本高且容易误触；正式版若保留三指，必须同时保留长按作为兜底，不允许只留一种高难度手势。

## 8 平板与折叠屏适配

| 断点 | 宽度 | 布局 |
| --- | --- | --- |
| 紧凑 | < 600dp | 单栏；底部导航（观看端）；摄像头端状态页单列 |
| 中等 | 600–839dp | 双栏：左侧设备列表，右侧实时画面；摄像头端状态与设置左右分栏 |
| 展开 | ≥ 840dp | 三栏：设备列表 / 实时画面 / 事件侧栏 |

折叠屏规则：

- 折叠态按紧凑断点渲染，展开态按中等断点渲染；不在折叠瞬间重建页面，只重排布局。
- 铰链区域禁止放置主按钮与手势热区，避免误触。
- 摄像头端横屏时控件整体下移，不遮挡画面中心（PRD §12.5）。

## 9 无障碍与夜间可用性

- 所有状态必须有文字，不允许只用颜色或图标表达。
- 最小点击热区 48dp；黑屏页整屏可点，不受热区限制。
- 支持系统字体放大到 1.3 倍不截断状态行。
- 夜间模式不做"更暗"第二套主题，仅通过降低提示文字 alpha 减少光污染。

## 11 验收清单

1. 摄像头端状态页在相机被占用时显示具体原因，而非一直"采集中"。
2. 黑屏页可见区域在暗室中不产生明显光斑，提示文字可隐藏。
3. 三种手势（单击 / 双击 / 长按）互不误触发，双击不产生两张照片。
4. 平板 600dp 以上为双栏，折叠屏展开 / 折叠切换不重建页面。
5. 所有状态色都配有文字说明。
